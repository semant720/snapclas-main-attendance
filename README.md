# 🎓 Smart Attendance System

An AI-powered attendance management system built using Streamlit, Supabase, and Face Recognition. The platform automates attendance tracking, reduces proxy attendance, and provides dedicated dashboards for teachers and students.

## ✨ Features

- Face ID Login
- Teacher & Student Dashboards
- Attendance Management
- Subject Enrollment
- Secure Authentication
- Real-Time Attendance Tracking

## 🚀 Installation

```bash
git clone <repository-url>
cd Smart-Attendance-System

python -m venv .venv
.venv\Scripts\activate

pip install -r requirements.txt
```

## ▶️ Run the Application

```bash
streamlit run main.py
```
